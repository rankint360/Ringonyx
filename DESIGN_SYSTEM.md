# Ringonyx design system

Near-black pages and graphite panels frame a single electric lime accent. Use lime for primary actions, focus, selected controls, and the hero emphasis. Green, amber, and rose are reserved for status, paired with text labels.

| Role | Color |
|---|---|
| Canvas | `#0B0E12` |
| Surface | `#121820` |
| Raised surface | `#1B2530` |
| Border | `#374655` |
| Text | `#F6F8FA` |
| Muted text | `#B5C0CA` |
| Primary accent | `#C6FF38` |
| Success | `#63E6B3` |
| Warning | `#FFBD66` |
| Error | `#FF858E` |

Use near-black text on filled lime buttons. Use Instrument Sans for interface copy and IBM Plex Mono for call data. Keep a 4 px spacing scale, 10 px control corners, and 20 px panel corners.

The Ringonyx mark uses a cut-corner lime tile with an open ring and a call waveform. Give it at least one quarter of its width as clear space. Repeat the angled corners in the homepage frame and primary call to action. Feature icons use rounded strokes on a 24 px grid. Tie motion to routing, ranking, and call outcomes, and respect reduced-motion preferences.
